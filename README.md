# 🚀 Project Overview

Welcome to the **TalkQuarium** project! This repository contains three main directories: **backend**, **frontend**, and **solution**. Each directory is structured for scalability and follows best practices to ensure maintainability.

---

## 📌 Features
- **Authentication**: Users can sign in with a simple username-based system.
- **Posts & Comments**: Users can create, view, edit, and delete posts and comments.
- **Role-Based Restrictions**: Users can only modify their own posts and comments.
- **Form Generator**: Dynamic form creation using React Hook Form.
- **API Documentation**: Built-in Swagger UI for easy API reference.
- **SQLite Database**: Lightweight, with auto-syncing schema.
- **Atomic Design Architecture**: Ensures reusability and maintainability of UI components.

---

## 📂 Directory Structure
```
root/
│-- backend/     # NestJS API with SQLite
```
